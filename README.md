# Bolsillos App — Fronteras Financieras: Del Caos al Control

Portafolio académico del proceso de Diseño de Experiencia de Usuario (UX) e Interacción Humano-Máquina para **Bolsillos App**, una herramienta diseñada para personas y emprendedoras con múltiples fuentes de ingreso que necesitan separar visualmente su dinero en tiempo real sin fricción manual.

## Organización del Repositorio
El repositorio está estructurado en la raíz con `index.html` (portafolio completo de proceso UX de las secciones 1 a 9), `css/estilos.css` (Sistema de Diseño de Bolsillos App accesible según WCAG 2.1 AA), `img/` (capturas de investigación, bocetos, evolución de prototipos y sistema de diseño), `anexos/` (evidencias crudas de investigación como guías de entrevista, CSV de encuestas y consentimientos) y `demo/` (carpeta reservada para el prototipo web interactivo de la Entrega Final).
